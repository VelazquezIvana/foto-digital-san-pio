# 📸 Foto Digital | Feria de Ciencias 2026

Aplicación web interactiva desarrollada para la **Feria de Ciencias 2026 del Instituto de Educación Superior San Pío de Pietrelcina**, en representación de la **Tecnicatura Superior en Desarrollo de Software**.

El proyecto permite a los visitantes crear una credencial digital personalizada con su fotografía y descargarla como recuerdo de su participación en la feria.

**Lema:** *Lo que imaginás, podés programarlo.*

## ✨ Funcionalidades

- 📷 Capturar una fotografía utilizando la cámara del dispositivo.
- 🖼️ Subir una imagen desde la galería.
- ✏️ Escribir un nombre o apodo.
- 👥 Personalizar la profesión, curso o grupo.
- 🎨 Elegir entre seis temas visuales que modifican los fondos, bordes y colores de la credencial.
- 💾 Generar y descargar la credencial en formato PNG.
- 📱 Acceder a la aplicación desde un celular mediante un código QR.
- 🔒 Procesar las fotografías localmente en el navegador, sin almacenarlas en un servidor.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura e interfaz.
- **CSS3:** diseño responsive, animaciones y temas visuales.
- **JavaScript:** interactividad y lógica de personalización.
- **Canvas API:** generación de la credencial como imagen.
- **MediaDevices API:** acceso a la cámara del dispositivo.
- **GitHub Pages:** publicación del sitio web.

## 🚀 ¿Cómo utilizarlo?

1. Abrir el sitio web o escanear el código QR.
2. Ingresar un nombre o apodo.
3. Escribir una profesión, curso o grupo.
4. Sacar una foto o subir una imagen.
5. Seleccionar el tema de la credencial.
6. Descargar la imagen personalizada.

## 🔐 Privacidad

Las fotografías se procesan en el navegador del usuario. La aplicación no requiere registro ni una base de datos para generar las credenciales.

## 🎓 Objetivo educativo

Demostrar cómo la programación web permite desarrollar experiencias interactivas mediante el uso de variables, funciones, eventos, condicionales y herramientas del navegador.
